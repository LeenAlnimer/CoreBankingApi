Quick Instructions

  1. Open Swagger and log in to get your JWT access token.
  2. Click Connect to Hub and paste the token.
  3. Confirm that the connection status says Connected.
  4. Create a transaction using the API in Swagger.
  5. Check the notification cards above.
  6. Transactions of at least 5000 JOD should also produce a Large Transaction Alert.
