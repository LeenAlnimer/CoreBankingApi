BankTask SignalR Transaction Test

This page helps you connect to the Transactions Hub and listen for TransactionCreated events.



  
  
  

  
Quick instructions

  
    
    
  1. Open Swagger and either create a user (/api/Auth/signup) or login (/api/Auth/login).
    2. 
    
  2. Copy the access token from the login response (do not paste it here in any public place).
    3. 
    
  3. Click Connect to Hub and paste the token when prompted.
    4. 
    
  4. Use the Get Connection Diagnostics button to confirm UserIdentifier matches your user id.
    5. 
    
  5. Create a Deposit transaction via /api/Transactions using your account id as destinationAccountId.
    6. 
    
  6. Watch for the TransactionCreated event in the log above.
    7.
